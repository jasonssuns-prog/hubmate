# 🧩 HubMate 助手（浏览器扩展）

桌面 Chrome / Edge 用的小扩展（Manifest V3），做网页版做不到的两件事：

1. **一键存为服务**：在任意网页点一下扩展图标 → “把当前网页存为服务”，直接存进你的服务台（用浏览器里服务台的登录状态）。
2. **登录页自动填充**：在有账号密码框的登录页，右下角会出现“🔑 从服务台填充”按钮，点一下按当前域名取账号，选一个填进账号/密码框。

## 安装（加载已解压的扩展程序）

1. 桌面 Chrome 或 Edge 打开 `chrome://extensions`（Edge 是 `edge://extensions`）。
2. 右上角打开**开发者模式**。
3. 点**加载已解压的扩展程序**，选这个 `browser-extension` 文件夹。
4. 工具栏出现 🗂️ 图标就装好了（看不到就点拼图图标把它钉出来）。

## 设置（只做一次）

1. 点扩展图标，填**服务台地址**（比如 `https://web.jasonsun.us`，不要带末尾的 `/`），点“保存设置”。
2. 在服务台网页里打开侧栏 **🔑 API 令牌**，点“生成令牌”，复制那串令牌。
3. 回到扩展弹窗，把令牌粘贴进 **API 令牌**框，点“保存设置”。

地址和令牌只存在本浏览器的 `chrome.storage.local` 里，不上传任何地方；换电脑要重新填。

## 用法

- **存当前网页**：在想收的网页上点扩展图标 → “把当前网页存为服务”。要求：已经在同一个浏览器里登录过服务台（没登录会提示先登录）。
- **登录页填充**：打开一个登录页（有密码框的页），右下角点“🔑 从服务台填充”，选一个账号就填好了。只会取当前域名的账号，别的域名的一律不取。
- **打开服务台**：弹窗里的“打开服务台”直接跳过去。

## 注意事项

- 需要服务端是 **v62 及以上**：按域名取账号用的是 `/api/accounts/by-domain` 接口（API 令牌鉴权，只返回匹配域名的账号），v62 之前没有这个接口。
- API 令牌只放行“按域名取账号”这一个读取接口，别的接口（包括签到）它不管；令牌在服务台里随时可以作废重发。
- 只支持桌面 Chrome / Edge；iOS / Android 的浏览器装不了扩展，用不了。
- 扩展本身不参与服务端部署：升级服务台不用管它，改了扩展代码后在 `chrome://extensions` 里点扩展卡片上的刷新按钮即可。

## 文件

| 文件 | 说明 |
|---|---|
| `manifest.json` | MV3 清单：弹窗、内容脚本、权限 |
| `popup.html` / `popup.js` | 弹窗：设置 + 一键存为服务 |
| `content.js` | 内容脚本：登录页浮动按钮 + 按域名取账号并填充 |
| `icons/` | 图标（复用服务台的图标） |
