**记录你注册过的一切**——签到站、中转站、VPS、游戏、订阅——每天打开签个到、看看到期，**一个页面管全部**。

纯 Node.js、**零依赖**（不用 `npm install`），数据存在本地一个 `data.json`，部署一条命令。

🌐 **在线演示**：[web.jasonsun.us](https://web.jasonsun.us) —— 作者本人的服务台，打开就能看到公开的网站列表和签到页；登录后的个人数据（账号、记事本、通知设置）不公开。

## 💡 为什么选 HubMate

- **零依赖**：纯 Node.js，不用 `npm install`，没有第三方包，不怕供应链出问题，部署一条命令
- **数据在自己手里**：所有数据只存在你服务器上的一个 `data.json`，不上传任何云端；备份、恢复、导出全由你掌控
- **免费**：MIT 开源，自己搭不要钱，能跑在免费小服务器上（Oracle Always Free、instabox 免费机）
- **轻量**：单文件存数据，资源占用小，一台 1 核小鸡就能跑
- **功能全**：签到、到期提醒、记事本、Telegram 通知、多账号、多服务器同步、GitHub 自动备份、自动签到、健康分、二次验证、日历订阅……一个页面管全部，不用装一堆 App
- **自托管**：除了可选的 Telegram / GitHub，不依赖任何第三方服务；局域网里也能用
- **手机友好**：可添加到主屏幕当 App 用，移动端专门优化过

## ✨ 功能

### 服务管理
- **增删改查**：名称、分类、网址、价格、备注；一个服务可以存多个账号（主号/小号）
- **账号管理**：卡片上的“👤 账号”打开单独的账号管理弹窗（和服务编辑页分开），里面能看账号、复制账号密码、签到、设默认、加账号、改账号、删账号；服务编辑页里没有账号字段，改账号不会误触服务信息
- **密码生成器**：账号管理弹窗里点“🎲 生成”，生成一个随机强密码（12/16/20/24 位，大小写+数字+符号，排除容易看错的字符），直接填进密码框
- **复制服务**：卡片上的“复制”一键复制出一个一样的服务（名字后加“副本”），签到记录和续期历史不带过去，账号带过去
- **批量编辑**：批量模式里除了移分类、删，还能一次给选中的多个服务改签到间隔、续期周期（空着的字段不动）
- **分类管理**：自定义分类（改名、换图标），只有空的自定义分类能删
- **收藏**：星标收藏，首页有“★ 我的收藏”区；分类“收藏”也会归拢进来
- **密码复用提醒**：同一个密码用在多个账号上就标出来（按密码分组，点眼睛看原文），提醒你换成不同的密码
- **批量操作**：批量勾选，批量改分类、批量删除
- **排序**：卡片 ↑ / ↓ 移动，顺序自己定
- **去重**：自动找出同名 / 同域名服务，一键清理
- **死链检测**：每 6 小时自动检测一次网址能不能打开，疑似失效标 ⚠️；每次检测都记一笔，卡片上显示这个站最近 7 天/30 天的在线率
- **搜索**：登录后按名称/账号/网址/备注搜；没登录也能搜首页的网站

### 签到与热情值
- **每日签到**：每天签到 +5⚡，首次签到才给分（防刷分）
- **多账号签到**：一个服务有几个账号，就得几个都签完才算这个站签到成功；每个账号单独签（账号管理弹窗里点），签到面板点一下把这个站没签的账号一次签完；进度按账号算百分比（已签 2/3 · 67%），圆环和全勤都按账号数算
- **签到间隔**：支持每 N 天签一次（1=每天），不到期不催
- **全勤奖励**：当天该签的都签完 +10⚡
- **签到撤回**：点错了能撤回（面板和卡片上都有“↩ 撤回”，账号管理弹窗里能单独撤一个账号）
- **一键全签**：一次签完当天所有未签的（多账号的站一次签完它全部账号）
- **等级与成就**：热情值升级、成就墙、连签天数、签到热力图、每日运势
- **标记异常**：网站暂时出问题、签到不了？勾上“⚠️ 标记异常”，卡片和签到行变红；标记的服务不算进全勤、一键全签和提醒，等恢复了再取消标记

### 到期与续费
- **临期提醒**：30 天内到期的服务列在侧栏（带数量角标），最急的排前面；7 天内到期的顶部有横幅
- **续期**：一律从今天起算（新到期日 = 今天 + 续期周期，提前续期不保留剩余天数；365 天按加一年，2 月 29 日变 2 月 28 日）
- **续期撤回**：续错了能撤回，恢复到续期前的日期
- **续期记录**：每次续期记一笔（哪天续的、从哪天续到哪天），临期行点“📜 记录”展开看，卡片上显示“上次续期”日期；撤回续期时对应的记录也拿掉
- **周期自动填**：到期日 = 注册/购买日期 + 续期周期，改其中一个自动填另一个；续期时注册日期也推到新周期起点，循环不断（手动改过到期日就不再自动覆盖）
- **到期日只改记录**：续期按钮只改这里的日期，不会替你去商家那续费付款
- **日历订阅**：公开的 `.ics` 订阅链接（`/api/calendar.ics`），加到 iPhone 日历里，所有到期日自动出现，到期前 3 天和 1 天各提醒一次；只含服务名和到期日，不含账号密码

### 记事本
- 登录后专用的记事本，**不显示在登录前的首页**
- 支持 **Markdown**（标题、粗斜体、代码块、列表、引用、链接），手机上有格式化工具栏和预览
- 搜索、展开阅读、编辑、删除；备份和恢复会自动包含记事本

### Telegram 通知
- 用 Telegram Bot API 推送：每天 17:00（可改）提醒未签到和临期服务，一天同一种最多一次，有事才推
- 机器人命令：`/today` 今日签到情况、`/expiring` 临期列表；提醒消息带“✅ 全部签到”按钮，点一下就签完
- 重复提醒可配（默认关闭）：固定提醒发完后，每隔 N 小时复查一次
- 设置页可测试，测试消息就是真实提醒的版式；Token 只存服务端，永不返回给前端

### API 令牌（iOS 快捷指令）
- 侧边栏“🔑 API 令牌”生成一个专用令牌，配 iOS 快捷指令不用打开网页就能签到；令牌只放行签到接口（全部签到、签一个服务），别的接口一律不认；令牌只在生成那一刻显示一次，丢了随时作废重发；备份导出时不含令牌

### 亮点功能（v60）
- **自动签到**：每个服务可配一个签到请求（网址 + 方法 + 请求头 + 正文 + 响应里要包含的文字），服务器每小时跑一轮，成功才记签到，失败不记、照常 Telegram 提醒你手动签。**只适合没有人机验证的纯接口签到，带验证码 / 登录表单的站签不了**；编辑页里有“测试这个请求”按钮
- **服务健康分**：每个服务一个 0–100 的健康分（在线率 + 到期远近 + 签到 + 死链），卡片上直接显示，数据中心里列出健康分最低的 5 个
- **登录二次验证**：TOTP 二次验证（Google / 微软 Authenticator、1Password 都行），密码对了还要输 6 位动态码；密钥只存在服务器上，备份里不带它
- **多标签**：一个服务可打多个标签（比如同时是“VPS”和“免费”），卡片上点标签、或标签栏点一下，就只看带这个标签的服务；搜索也能搜到标签
- **公开状态页**：登录前的首页加了“服务状态”区，公开显示每个服务的在线 / 离线和 7 天在线率
- **账号导出**：全部已录账号导出为 CSV，可直接导进 1Password、Bitwarden；文件里含密码，妥善保管
- **GitHub 自动备份**：配好 Token 和私有仓库后，每天自动把数据推到仓库里的 `hubmate-backup.json`（Git 历史就是备份历史），数据没变就不推；推之前去掉登录密码、Telegram Token、API 令牌、二次验证密钥和自动签到的请求头

### 多服务器同步（v61）
- 把服务台同时部署在几台服务器上，数据自动同步：一台宕机了用另一台继续，宕机的那台启动后 30 秒内自动从对方拉最新数据
- 每台服务器配同一个同步口令（只在自己的服务器之间用，能读写整盘数据，别外泄）和对方的地址；启动时和每 5 分钟跟对方比一次，谁的数据更新就赢，赢的那份整盘同步过去
- 同步前自动备份当前数据（保留最近 5 份）；注意：别在同一秒内往两台服务器上写东西，平时只用一台写，另一台就是热备

### 新功能（v62）
- **书签导入**：Chrome / Edge / Safari 导出的书签 HTML 一键导入成服务，同网址已存在的跳过
- **账号 CSV 导入**：按服务名匹配已有服务，把账号批量追加进去（和账号导出的表头一致，可原样导回）；找不到的服务和已存在的账号会跳过并上报
- **多渠道通知**：除了 Telegram，还能同时推到 Webhook（POST JSON）、Bark（iPhone 推送）和 Server酱（微信推送）；测试按钮按渠道逐个报结果
- **在线率趋势**：数据中心新增面板，选一个服务看近 30 天每天的探活成功率走势图
- **全局搜索**：顶部一个搜索框同时搜服务、账号、记事，分组显示，点结果直接跳过去
- **自定义字段**：每个服务可加最多 10 个自定义键值对（比如邀请码、客服邮箱），编辑页里加行/删行，卡片上显示
- **浏览器扩展**：桌面 Chrome / Edge 用（`browser-extension/`，仓库里的附加产物）：一键把当前网页存为服务，登录页按域名一键填充账号；加载方法见 `browser-extension/README.md`
- **修复**：恢复备份不再丢多账号和“标记异常”（之前恢复只认默认账号，其他账号会被丢掉）

### 新功能（v65）
- **共享账号库**：一个账号只存一份（侧边栏“🗝️ 账号库”），多个服务可以链接同一个库账号；改库里的密码，所有链接的服务都跟着变；删库账号时，链接的服务自动变回本地副本（当时的账号密码快照存回服务里，不丢数据）；账号管理弹窗里有“从账号库选择”和“存入账号库”
- **账号安全评分**：每个账号一个 0–100 的安全分（密码长度 + 字符种类 − 复用 − 超 90 天没换），卡片和账号弹窗里直接显示分数和弱点，数据中心列出最不安全的 5 个账号
- **SSL 证书到期监控**：每 6 小时死链检测时顺手取 https 站的证书到期日，卡片和临期面板显示“证书 X 天后到期”，30 天内标红
- **智能分类推荐**：加服务 / 编辑服务时，按域名和关键词自动推荐分类和标签（比如 github→开发、vps→VPS、gmail→邮箱），点一下就填上
- **密码轮换提醒**：超过 90 天没换的账号列在数据中心“该换密码了”里（服务名 + 账号名 + 上次改密日期 + 去改按钮）；每天 17:00 的 Telegram 提醒里加一句有几个账号该换密码了
- **月度报告**：每月 1 号自动生成上月报告并推 Telegram（签到天数、总签到次数、签到攒的经验、最常签到的服务、新增服务数、到期提醒数、本月在线率最低的 3 个服务）；数据中心“月度报告”面板列出最近 6 个月；侧边栏有“手动生成上月报告”按钮
- **签到分享卡片**：数据中心“📤 分享我的签到”按钮，在浏览器里用 canvas 画一张成绩卡（本月签到天数、总连签天数、XP、等级、最常签到的服务），下载 PNG 自己发朋友圈 / 群
- **登录历史与异地提醒**：每次登录成功记一条（时间、IP、设备），设置里“🕐 最近登录”列出最近 10 条；换了个新 IP 登录时发 Telegram 提醒；登录接口不返回历史
- **到期自动归档**：到期超过 30 天没续的服务，每天自动归到“🗄️ 已归档”分类（分类不存在就自动建），归档的服务不再计入签到队列、临期提醒和 Telegram 提醒；台账里归档分类默认折叠，手动把分类改回来就恢复正常
- **快捷指令模板**：仓库 `shortcuts/` 里有两份现成的 iOS 快捷指令说明（“全部签到”“查今日到期”），按步骤在快捷指令 App 里搭好就能用，不用打开网页；查到期要用浏览器打开页面（API 令牌只放行签到接口）
- **月度可用性报告**：数据中心“本月可用性”面板，按本月在线率从低到高列出服务（在线率 + 探测次数，没探测记录的显示“无数据”）；每月 1 号随月度报告一起推 Telegram（最低的 3 个）

### 新功能（v67）
- **多用户（邀请码注册）**：第一个默认用户是管理员，其他人注册必须凭邀请码（登录页点“注册账号”，填用户名、密码、邀请码）；邀请码只有管理员能在设置里生成（`HUB-XXXX-XXXX-XXXX`，随机 12 位无歧义字符），一个码只能用一次，用过即作废；管理员能看邀请码列表（创建时间、是否已用、被谁用了）并作废未用的码
- **各看各的数据**：每个用户只能看到自己的服务、笔记、账号库、签到、经验、分类、通知设置等，互相看不到；公开落地页（未登录看到的）显示管理员的公开服务，和以前一样；其他功能（服务、签到、笔记、提醒、备份、同步、二次验证、API 令牌等）每个用户都有、用起来一样
- **我的账号**：设置里“👤 我的账号”可以改自己的用户名（要输当前密码确认，全站唯一）和改密码（已有功能），并看最近登录；第一个默认用户改名也走这个入口
- **用户管理（仅管理员）**：设置里“👥 用户管理”面板能看所有注册用户的账号信息（用户名、注册时间、是否封禁、最后登录时间、服务数、经验），能直接创建用户（不用邀请码）、改别人的用户名、重置别人的密码（重置后是默认密码状态，下次登录提示改密码；新密码只显示一次）、封禁 / 解封用户（被封禁的登录时拒绝，数据保留）、删除用户（删账号及该用户全部数据，需二次确认，不能删自己）；管理员看不到也改不了任何用户的服务、笔记、账号等业务数据
- **备份与同步（多用户下）**：GitHub 自动备份和多服务器同步仍是整盘、服务器级的（所有用户的数据都在里面，管理员配）；手动备份时管理员下载整盘，普通用户只下载自己的数据；恢复时按用户归属恢复，不会串到别的用户；备份里永远不含任何用户的密码哈希
- **迁移**：第一次启动 v67 时自动把老数据迁进管理员账号（服务、笔记、经验、分类、通知等原样，一条不丢），老会话（登录态）第一次请求时默认归管理员，不用重新登录

### 备份与安全
- **备份 / 恢复**：一键下载备份（自动去掉登录密码哈希、Telegram Token、API 令牌、二次验证密钥、同步口令和自动签到的请求头），恢复时自动保存当前数据（保留最近 5 份）
- **导出台账**：生成一份 `服务台账.md`，方便翻看
- **登录验证码**：内置图片验证码（一次性，5 分钟过期，先验验证码再验密码）+ 单 IP 限流（10 次 / 10 分钟）
- **安全响应头 + CSP、gzip、ETag 缓存**，systemd 沙箱低权限用户运行

### 数据与主题
- **年度总结**：一张今年回顾卡——签到天数、总次数、签到攒的经验、最常签到的服务
- **跟随系统主题**：第 5 个主题点“跟随系统”，浅色/深色自动跟随手机系统设置

### 手机友好
- 移动端布局优化：面板说明可折叠、分类组可折叠、返回顶部只在上滑时出现
- 支持**添加到主屏幕**（PWA manifest + 图标，无 Service Worker）

## 🚀 快速开始

### 本机运行
```bash
node server.js
# 打开 http://127.0.0.1:7788
```
Windows 也可以双击 `start.bat`（关掉黑窗口 = 停止服务）。默认端口 7788，可用环境变量 `PORT` 改。

默认账号 `jason` / 密码 `jason123` —— **登录后请点右上角「改密码」换掉**。

### 部署到服务器（2 分钟）
```bash
git clone https://github.com/jasonssuns-prog/hubmate.git /opt/service-hub
cd /opt/service-hub && sudo bash deploy/install.sh
```
脚本自己装 Node.js、建低权限用户、配 systemd 开机自启、做健康检查。装完打开 `http://服务器IP:7788`，默认账号 `jason` / `jason123`，登录后第一件事改密码。更多选项（nginx 反代、HTTPS、换端口）看 [`DEPLOY.md`](./DEPLOY.md)。

### 自定义域名（Cloudflare）
`cloudflare-worker/` 里有一个反代 Worker：把你自己的域名绑定到这个 Worker，它会把访问转发到你部署好的服务，地址栏全程保持你的域名。详见 [`cloudflare-worker/README.md`](./cloudflare-worker/README.md)。

> **Cloudflare Workers 一键部署？** 目前不支持：本项目是 Node.js 服务端（监听端口 + 本地文件存数据），Workers 是无服务器运行时，没有持久文件系统和 TCP 监听，所以 [Deploy to Cloudflare](https://developers.cloudflare.com/workers/platform/deploy-buttons/) 按钮无法直接部署它。想把它做成 Workers 原生版（KV / D1 存数据）是另一个大工程，有兴趣可以提 Issue 讨论。

## 🔔 Telegram 设置

1. 在 Telegram 找 [@BotFather](https://t.me/BotFather) 创建机器人，拿到 Token。
2. 登录服务台 → 侧栏“🔔 通知设置”填入 Token，保存。
3. 在 Telegram 给你的机器人发 `/start`（必须先打招呼，机器人才能拿到你的 Chat ID）。
4. 点“自动获取 Chat ID”，再点“发送测试”，收到测试消息就通了。

Token 只存在服务端的 `data.json`，不会出现在前端和备份文件里。**不要把 Token 发到聊天群或贴到公开地方**，泄露了要在 @BotFather 重新生成。

## ☁️ GitHub 自动备份设置

1. 在 GitHub 新建一个**私有**仓库（比如 `hubmate-data`），空仓库就行，不用勾 README / .gitignore / license。
2. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)，Note 随便写（比如 `hubmate-backup`），Expiration 选 No expiration，勾选 `repo` 权限，生成后**只显示一次**，复制好。
3. 登录服务台 → 侧栏“☁️ GitHub 备份”，填入 Token、仓库（`你的用户名/仓库名`，比如 `jasonssuns-prog/hubmate-data`）、分支（默认 `main`），点保存，再点“立即备份”。
4. 配好后每天自动备份一次（数据没变就不推）；备份文件是仓库里的 `hubmate-backup.json`，Git 历史就是备份历史。

备份前会自动去掉登录密码哈希、Telegram Token、API 令牌、二次验证密钥、同步口令和自动签到的请求头。Token 泄露了在 GitHub 上删掉重建一个，再到面板里更新。

## 💾 数据

所有数据存在 `data/data.json`（服务、分类、记事本、设置、签到记录都在里面）。服务每次启动都会重新读取，直接改这个文件也行。

> 备份文件里**不含**登录密码哈希、Telegram Token、API 令牌、二次验证密钥、同步口令和自动签到的请求头；恢复备份时这些值会保留当前值。
