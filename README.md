**记录你注册过的一切**——签到站、中转站、VPS、游戏、订阅——每天打开签个到、看看到期，**一个页面管全部**。

纯 Node.js、**零依赖**（不用 `npm install`），数据存在本地一个 `data.json`，部署一条命令。

🌐 **在线演示**：[web.jasonsun.us](https://web.jasonsun.us) —— 作者本人的服务台，打开就能看到公开的网站列表和签到页；登录后的个人数据（账号、记事本、通知设置）不公开。

## ✨ 功能

### 服务管理
- **增删改查**：名称、分类、网址、账号、密码/密钥、价格、备注；一个服务可以存多个账号（主号/小号），卡片上展开就能一键复制账号密码再跳转
- **分类管理**：自定义分类（改名、换图标），只有空的自定义分类能删
- **收藏**：星标收藏，首页有“★ 我的收藏”区；分类“收藏”也会归拢进来
- **密码复用提醒**：同一个密码用在多个账号上就标出来（按密码分组，点眼睛看原文），提醒你换成不同的密码
- **批量操作**：批量勾选，批量改分类、批量删除
- **排序**：卡片 ↑ / ↓ 移动，顺序自己定
- **去重**：自动找出同名 / 同域名服务，一键清理
- **死链检测**：每 6 小时自动检测一次网址能不能打开，疑似失效标 ⚠️
- **搜索**：登录后按名称/账号/网址/备注搜；没登录也能搜首页的网站

### 签到与热情值
- **每日签到**：每天签到 +5⚡，首次签到才给分（防刷分）
- **多账号签到**：一个服务有几个账号，就得几个都签完才算这个站签到成功；每个账号单独签（账号面板里点），签到面板点一下把这个站没签的账号一次签完；进度按账号算百分比（已签 2/3 · 67%），圆环和全勤都按账号数算
- **签到间隔**：支持每 N 天签一次（1=每天），不到期不催
- **全勤奖励**：当天该签的都签完 +10⚡
- **签到撤回**：点错了能撤回（面板和卡片上都有“↩ 撤回”，账号面板里能单独撤一个账号）
- **一键全签**：一次签完当天所有未签的（多账号的站一次签完它全部账号）
- **等级与成就**：热情值升级、成就墙、连签天数、签到热力图、每日运势
- **标记异常**：网站暂时出问题、签到不了？勾上“⚠️ 标记异常”，卡片和签到行变红；标记的服务不算进全勤、一键全签和提醒，等恢复了再取消标记

### 到期与续费
- **临期提醒**：30 天内到期的服务列在侧栏（带数量角标），最急的排前面；7 天内到期的顶部有横幅
- **续期**：按服务自己的续期周期顺延（未过期的从原到期日起，已过期的从今天起；365 天按加一年，2 月 29 日变 2 月 28 日）
- **续期撤回**：续错了能撤回，恢复到续期前的日期
- **周期自动填**：到期日 = 注册/购买日期 + 续期周期，改其中一个自动填另一个；续期时注册日期也推到新周期起点，循环不断（手动改过到期日就不再自动覆盖）
- **到期日只改记录**：续期按钮只改这里的日期，不会替你去商家那续费付款
- **日历订阅**：公开的 `.ics` 订阅链接（`/api/calendar.ics`），加到 iPhone 日历里，所有到期日自动出现，到期前 3 天和 1 天各提醒一次；只含服务名和到期日，不含账号密码

### 记事本
- 登录后专用的记事本，**不显示在登录前的首页**
- 支持 **Markdown**（标题、粗斜体、代码块、列表、引用、链接），手机上有格式化工具栏和预览
- 搜索、展开阅读、编辑、删除；备份和恢复会自动包含记事本

### Telegram 通知
- 用 Telegram Bot API 推送：每天 17:00（可改）提醒未签到和临期服务，一天同一种最多一次，有事才推
- 机器人命令：`/today` 今日签到情况、`/expiring` 临期列表；提醒消息带“✅ 全部签到”按钮，点一下就签完
- 重复提醒可配（默认关闭）：固定提醒发完后，每隔 N 小时复查一次
- 设置页可测试，测试消息就是真实提醒的版式；Token 只存服务端，永不返回给前端

### 备份与安全
- **备份 / 恢复**：一键下载备份（自动去掉登录密码哈希和 Telegram Token），恢复时自动保存当前数据（保留最近 5 份）
- **导出台账**：生成一份 `服务台账.md`，方便翻看
- **登录验证码**：内置图片验证码（一次性，5 分钟过期，先验验证码再验密码）+ 单 IP 限流（10 次 / 10 分钟）
- **安全响应头 + CSP、gzip、ETag 缓存**，systemd 沙箱低权限用户运行

### 数据与主题
- **年度总结**：一张今年回顾卡——签到天数、总次数、签到攒的经验、最常签到的服务
- **跟随系统主题**：第 5 个主题点“跟随系统”，浅色/深色自动跟随手机系统设置

### 手机友好
- 移动端布局优化：面板说明可折叠、分类组可折叠、返回顶部只在上滑时出现
- 支持**添加到主屏幕**（PWA manifest + 图标，无 Service Worker）

## 🚀 快速开始

### 本机运行
```bash
node server.js
# 打开 http://127.0.0.1:7788
```
Windows 也可以双击 `start.bat`（关掉黑窗口 = 停止服务）。默认端口 7788，可用环境变量 `PORT` 改。

默认账号 `jason` / 密码 `jason123` —— **登录后请点右上角「改密码」换掉**。

### 部署到服务器
看 [`DEPLOY.md`](./DEPLOY.md)：一条 `bash deploy/install.sh` 搞定（systemd 常驻 + 可选 nginx 反代 + HTTPS）。

### 自定义域名（Cloudflare）
`cloudflare-worker/` 里有一个反代 Worker：把你自己的域名绑定到这个 Worker，它会把访问转发到你部署好的服务，地址栏全程保持你的域名。详见 [`cloudflare-worker/README.md`](./cloudflare-worker/README.md)。

> **Cloudflare Workers 一键部署？** 目前不支持：本项目是 Node.js 服务端（监听端口 + 本地文件存数据），Workers 是无服务器运行时，没有持久文件系统和 TCP 监听，所以 [Deploy to Cloudflare](https://developers.cloudflare.com/workers/platform/deploy-buttons/) 按钮无法直接部署它。想把它做成 Workers 原生版（KV / D1 存数据）是另一个大工程，有兴趣可以提 Issue 讨论。

## 🔔 Telegram 设置

1. 在 Telegram 找 [@BotFather](https://t.me/BotFather) 创建机器人，拿到 Token。
2. 登录服务台 → 侧栏“🔔 通知设置”填入 Token，保存。
3. 在 Telegram 给你的机器人发 `/start`（必须先打招呼，机器人才能拿到你的 Chat ID）。
4. 点“自动获取 Chat ID”，再点“发送测试”，收到测试消息就通了。

Token 只存在服务端的 `data.json`，不会出现在前端和备份文件里。**不要把 Token 发到聊天群或贴到公开地方**，泄露了要在 @BotFather 重新生成。

## 💾 数据

所有数据存在 `data/data.json`（服务、分类、记事本、设置、签到记录都在里面）。服务每次启动都会重新读取，直接改这个文件也行。

> 备份文件里**不含**登录密码哈希和 Telegram Token；恢复备份时 Token 会保留当前值。
