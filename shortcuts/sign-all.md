# 快捷指令：全部签到

**一句话**：在 iPhone 上点一下，今天所有没签的服务一次签完，不用打开服务台网页。

## 先准备

1. **服务台地址**：比如 `https://web.jasonsun.us`（你自己的域名），或 `http://<你的服务器IP>:7788`。下面步骤里的 `你的服务台地址` 都换成它。
2. **API 令牌**：在服务台网页侧边栏「🔑 API 令牌」里点「生成令牌」，复制那串字符（只在生成那一刻显示一次）。

## 配置步骤

1. 打开 iPhone「快捷指令」App → 右上角 `+` 新建快捷指令。
2. 搜索并添加动作 **「获取 URL 内容」**。
3. 点开这个动作，按下面填：
   - **URL**：`你的服务台地址/api/checkins/all`
     - 比如 `https://web.jasonsun.us/api/checkins/all`
   - **方法**：选 `POST`
   - **请求头**：点「添加新字段」，填两栏
     - 键（Key）：`Authorization`
     - 值（Value）：`Bearer 你的API令牌`
     - 比如 `Bearer a1b2c3d4e5f6…`（`Bearer` 后面有个空格，再接令牌）
   - **请求体**：不用填（留空）。
4. 再搜索并添加动作 **「显示结果」**（或「显示通知」），选刚才「获取 URL 内容」的结果。
   - 返回的 JSON 里有 `signed`（这次签了几个）、`xpGained`（得了几点热情值）、`allDone`（是不是全签完了）。
5. 点右上角完成，改名「服务台全部签到」。
6. （可选）长按这个快捷指令 → 分享 → 添加到主屏幕，以后点图标就能签。

## 想只签某一个服务

把上面第 3 步的 URL 换成：

```
你的服务台地址/api/services/服务编号/checkin
```

- 「服务编号」是服务在服务台里的 id（在网页上点开服务卡片，地址栏或编辑框里能看到；也可以先用「全部签到」，一般用不到这一个）。
- 方法、请求头和上面一样（POST + `Authorization: Bearer <令牌>`）。

## 注意事项

- **令牌只放行签到接口**：`POST /api/checkins/all` 和 `POST /api/services/:id/checkin`。别的接口（查到期、改数据）都不认令牌，一定要登录会话才行。
- 令牌不要发给别人，也不要放进公开分享的快捷指令里；丢了随时在「🔑 API 令牌」里作废重发，记得把快捷指令里的令牌也换成新的。
- 如果返回 401：令牌不对或被作废了，重新生成一个再填进去。
- 每天首次签到 +5 热情值、全签完再 +10，和网页上签到完全一样；已经签过的不会重复给分。
