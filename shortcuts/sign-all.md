# 快捷指令：全部签到

一键签完今日所有还没签的服务，不用打开网页。适合每天起床 / 睡前点一下。

## 需要准备

- HubMate 的 API 令牌（在 HubMate「🔑 API 令牌」面板点「生成令牌」复制）。
- 你的 HubMate 地址（比如 `https://web.jasonsun.us`）。

## 搭建步骤（iPhone「快捷指令」App）

1. 打开「快捷指令」→ 右上角 `+` 新建。
2. 添加动作「获取 URL 内容」（搜索 `URL` 就能找到）。
3. 点开这个动作，设置：
   - **URL**：填 `你的地址/api/checkins/all`，比如 `https://web.jasonsun.us/api/checkins/all`
   - **方法**：选 `POST`
4. 点开「获取 URL 内容」里的「更多」（或点 `展开`），加一个请求头：
   - 点「添加新标头」，**键**填 `Authorization`，**值**填 `Bearer 你的令牌`
   - 比如令牌是 `abc123…`，值就填 `Bearer abc123…`（`Bearer` 后面有个空格）
5. 再加一个动作「显示通知」（搜索 `通知`），内容填 `已签到`（或者留空，看到通知就知道跑完了）。
6. 点右上角完成，改名「全部签到」。

## 想签某一个服务

把第 3 步的 URL 结尾换成 `/api/services/服务编号/checkin`。

服务编号在哪看？在 HubMate 里点开这个服务的「编辑」，浏览器地址栏不会显示编号——
简单办法：先用「全部签到」就行，大多数人不需要单独签某一个。

## 常见问题

- **点了没反应 / 通知说失败**：先检查令牌对不对（复制时别多复制了空格）、地址对不对（`https://` 别写成 `http://`）、服务器在不在运行。
- **令牌丢了 / 怀疑泄露**：去 HubMate「🔑 API 令牌」面板点「作废令牌」，再生成一个新的，然后把快捷指令里的旧令牌换掉。
- **签到会不会重复加分**：不会。同一天重复签只记一次，经验也只加一次。
