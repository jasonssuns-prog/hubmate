# 快捷指令：查今日到期

快速打开 HubMate 看今天有哪些服务到期 / 要签到。

## 为什么不能像「全部签到」那样直接查

API 令牌**只放行签到接口**（全部签到、签一个服务），这是故意设计的：令牌就算泄露，别人也只能帮你签到，改不了数据、看不到账号密码。

查到期、查签到情况要读你的全部数据，令牌不放行这个接口，所以必须**打开浏览器页面**看。

## 搭建步骤（iPhone「快捷指令」App）

1. 打开「快捷指令」→ 右上角 `+` 新建。
2. 添加动作「打开 URL」（搜索 `打开 URL`）。
3. URL 填你的 HubMate 地址 + `#sec-expiring`，比如：
   - `https://web.jasonsun.us/#sec-expiring`（直接跳到临期提醒）
   - 想先看今日签到，填 `https://web.jasonsun.us/#sec-checkin`
4. 点右上角完成，改名「查今日到期」。

## 更顺手的做法

- 把这个快捷指令加到主屏幕（快捷指令详情页 → 分享 → 添加到主屏幕），每天点一下就看到期列表。
- 或者直接把 HubMate 添加到主屏幕（浏览器里点分享 → 添加到主屏幕），效果一样，还不用搭快捷指令。
- 每天 17:00（可在通知设置里改）Telegram 也会推一条临期提醒，不用自己查。
