# 快捷指令：查今日到期

**一句话**：在 iPhone 上点一下，看看今天和 30 天内有哪些服务要到期，不用打开服务台网页、不用登录。

## 为什么不用 API 令牌

API 令牌**只放行签到接口**（`POST /api/checkins/all` 和 `POST /api/services/:id/checkin`），查到期、查签到情况这些接口都不认令牌，一定要登录会话才行——快捷指令里没法保持登录会话。

所以这个模板走的是**公开接口** `GET /api/public`：它和登录前首页看到的内容一样（服务名、到期日、签到状态），不含账号密码，不用登录就能拉。

## 先准备

- **服务台地址**：比如 `https://web.jasonsun.us`（你自己的域名），或 `http://<你的服务器IP>:7788`。下面步骤里的 `你的服务台地址` 都换成它。

## 配置步骤（简易版：直接显示原文）

1. 打开 iPhone「快捷指令」App → 右上角 `+` 新建快捷指令。
2. 搜索并添加动作 **「获取 URL 内容」**。
3. 点开这个动作，按下面填：
   - **URL**：`你的服务台地址/api/public`
     - 比如 `https://web.jasonsun.us/api/public`
   - **方法**：选 `GET`
   - 请求头、请求体都不用填。
4. 再搜索并添加动作 **「显示结果」**，选刚才「获取 URL 内容」的结果。
5. 点右上角完成，改名「服务台查到期」。

这样点一下就能看到全部服务的 JSON 原文（含每个服务的 `expiresAt` 到期日）。想看得清爽一点，继续往下做进阶版。

## 配置步骤（进阶版：只列出 30 天内到期的）

在上面第 3 步之后，插入下面几个动作，把 JSON 里的临期服务筛出来：

1. 添加动作 **「获取词典值」**：
   - 词典：选「获取 URL 内容」的结果
   - 键：`services`
2. 添加动作 **「重复每一个项目」**（对 services 数组里的每个服务跑一遍）：
   - 在循环里加动作 **「获取词典值」**：
     - 词典：选「重复项目」
     - 键：`expiresAt`
   - 再加动作 **「如果」**，条件是「重复项目」的 `expiresAt` 不为空、且在 30 天内（快捷指令里用「格式化日期」和「调整日期」算出 30 天后的日期再比较）。
   - 在「如果」里面加动作 **「获取词典值」**（键 `name`）和 **「合并文本」**，把「名字 + 到期日」拼成一行，加进一个变量。
3. 循环结束后，加动作 **「显示结果」**，显示拼好的文本。

> 进阶版涉及日期比较，步骤比较绕；如果搭起来麻烦，先用简易版（直接看 JSON 原文），到期日都在里面，一眼就能找到。

## 注意事项

- 公开接口返回的是和首页一样的内容：服务名、到期日、签到状态、分类，不含账号、密码、备注、通知设置，不用担心泄露。
- 如果你的服务台还没配域名、只在内网能访问，快捷指令在外面（4G/5G）是连不上的——先用上面「全部签到」模板里的域名方式，或在家里 Wi-Fi 下用。
- 想在手机日历里自动看到所有到期日（到期前 3 天和 1 天各提醒一次），用服务台网页侧边栏「📅 日历订阅」里的订阅链接，比快捷指令更省事。
