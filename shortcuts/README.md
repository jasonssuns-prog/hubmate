# iOS 快捷指令模板

不用打开网页，在 iPhone 上点一下就能签到、查到期。两个模板都是**按说明在手机上现搭**的，不需要下载任何文件，也没有 `.shortcut` 二进制文件可导。

> ⚠️ 先准备两样东西（只填一次）：
>
> 1. **你的服务台地址**：比如 `https://web.jasonsun.us`（你自己的域名），或服务器的 `http://<IP>:7788`。下面所有步骤里的 `你的服务台地址` 都换成它。
> 2. **API 令牌**：在服务台网页侧边栏「🔑 API 令牌」里点「生成令牌」，复制那串字符。**令牌只放行签到接口**，别的接口一律不认；丢了随时作废重发。

## 两个模板

| 模板 | 文件 | 作用 | 要令牌吗 |
| --- | --- | --- | --- |
| ① 全部签到 | [sign-all.md](sign-all.md) | 一键签完今天所有未签的服务 | 要（Header 里带 `Authorization: Bearer <令牌>`） |
| ② 查今日到期 | [check-expiring.md](check-expiring.md) | 看今天/30 天内有哪些服务要到期 | 不要（走公开接口 `/api/public`，不用登录） |

## 为什么“查到期”不用令牌

API 令牌**只放行签到接口**（`POST /api/checkins/all` 和 `POST /api/services/:id/checkin`），查到期、查签到情况这些接口都不认令牌，一定要登录会话才行。所以「查今日到期」走的是**公开接口** `GET /api/public`——它和登录前首页看到的内容一样（服务名、到期日、签到状态），不含账号密码，不用登录就能拉。

## 通用做法（两个模板都一样）

1. 打开 iPhone「快捷指令」App → 右上角 `+` 新建。
2. 搜「获取 URL 内容」加进来，按各模板文件里写的填 URL、方法、请求头。
3. 再加一个「显示结果」或「显示通知」，把返回内容显示出来。
4. 点右上角完成，改个名字（比如「服务台签到」），可以加到主屏幕或设个自动化（比如每天 17:00 自动跑）。

## 安全提醒

- API 令牌不要发给别人，也不要放进公开分享的快捷指令里。
- 快捷指令里的 URL 和令牌只存在你自己的手机上，不会上传到任何地方。
- 想换令牌：在服务台「🔑 API 令牌」里点「作废令牌」再重新生成，然后把快捷指令里的令牌也换成新的。
