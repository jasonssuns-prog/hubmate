# HubMate iOS 快捷指令模板

不用从零搭：照着下面两个说明，在 iPhone 的「快捷指令」App 里按步骤搭好就能用。

## 前置条件

1. 在 HubMate 的「🔑 API 令牌」面板点「生成令牌」，复制那串令牌（只显示一次，丢了就作废重发）。
2. 把你的 HubMate 地址记下来（比如 `https://web.jasonsun.us`，或你的服务器地址 + `:7788`）。

## 两个模板

| 文件 | 快捷指令 | 说明 |
|---|---|---|
| [sign-all.md](sign-all.md) | 全部签到 | 一键签完今日所有服务，不用打开网页 |
| [check-expiring.md](check-expiring.md) | 查今日到期 | 打开页面看今日到期（令牌只放行签到接口，查到期要走浏览器） |

## 安全提醒

- **令牌只放行签到接口**（全部签到、签一个服务），别的接口一律不认——就算令牌泄露，别人也只能帮你签到，改不了数据、看不到账号密码。
- **令牌不要发给别人，也不要放进公开分享的快捷指令里。** 怀疑泄露了就去「🔑 API 令牌」面板点「作废令牌」，再生成一个新的，旧的立刻失效。
- 快捷指令里的令牌存在你的手机上，不会同步到 iCloud（除非你自己开了同步）。
