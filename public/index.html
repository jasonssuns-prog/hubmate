📈 年度总结

★ 我的收藏管理

在这里统一管理收藏：点卡片上的 ☆ 可以添加，点 ★ 可以取消；也可以在编辑服务时勾选收藏。

⏰ 临期提醒

30 天内到期（含已过期）的服务，按最紧急的排在最前。点名称直达官网去办理，办完后点“编辑”更新到期时间。证书那行是 SSL 证书到期日（<30 天标红），证书过期了网站会打不开，和服务到期是两回事。到期超过 30 天没续的服务每天会自动归到“已归档”分类，归档的不进签到和临期提醒，手动改回分类就恢复。

📅 日历订阅

把到期日订阅到手机日历，所有服务的到期日自动出现在日历上，到期前 3 天和 1 天各提醒一次。订阅链接里只有服务名和到期日，不含账号密码；服务续期改了日期，日历下次抓取会自动更新。

  1. iPhone：设置 → 日历 → 帐户 → 添加帐户 → 其他 → 添加已订阅的日历，粘贴上面复制的链接，点“下一步”再点“存储”。
  2. 订阅成功后，打开日历就能看到每个服务的到期日（全天事件，标题是“服务到期：名字”）。
  3. 不想订阅了，在同一个地方点进这个已订阅的日历，拉到底点“删除帐户”。

🔔 通知设置

通过 Telegram 机器人推送提醒。Token 只存在你的服务器上，设置页不会把它显示出来；两个开关各管一种提醒，每天到你设定的时间后各推一次，有事才推，没事不打扰。签到提醒还可以在固定时间后每隔几小时重复推一次（23 点后不推，签完即停），间隔填 0 表示不重复。注意：沙箱休眠时推送会暂停，醒来后补推。机器人还支持 /today、/expiring 命令查询。除了 Telegram，还能同时推到 Webhook（POST JSON 到你填的地址）、Bark（iPhone 推送）和 Server酱（微信推送），三个渠道都可选配，密钥只存服务端，测试按钮会逐个渠道告诉你发没发出去。

🔑 API 令牌

给 iOS 快捷指令用的令牌：不用打开网页就能签到。令牌只放行签到接口（全部签到、签一个服务），别的接口一律不认；令牌只在生成那一刻显示一次，平时只告诉你有没有，丢了随时作废重发。令牌不要发给别人，也不要放进公开的快捷指令分享里。

🔐 二次验证

给登录再加一层：密码对了还要输手机 Authenticator（Google Authenticator、微软 Authenticator、1Password 都行）里的 6 位动态码。密钥只存在你的服务器上，备份里不带它；启用前先在手机里绑好，输一次动态码确认。关掉也要密码 + 动态码双重确认。

还没生成密钥

启用步骤：点“生成密钥”→ 在 Authenticator 里手动添加账号，密钥填上面那串（或把 otpauth 链接粘到支持的工具里）→ 输一次动态码点“启用二次验证”。

👤 我的账号

改用户名要输当前密码确认，用户名全站唯一，不能重名。改密码用侧栏「⚙️ 密码修改」。登录后看到提示「请改掉默认密码」时先改掉它。

🕐 最近登录

最近 10 次

每次登录成功记一条（时间、IP、设备）。如果某次登录的 IP 和上一次不一样，会推一条异地登录提醒到 Telegram / 你配的其他渠道；不是你登的，立刻改密码。

👥 用户管理

这里只看账号信息——用户名、注册时间、封禁状态、最后登录。管理员看不到也改不了任何用户的服务、笔记、账号等业务数据。删除会连同该用户全部数据一起删掉，不能删自己。

🎟️ 邀请码

注册要邀请码（第一个默认用户除外）。每个码只能用一次，注册成功即消耗。把码发给要注册的人，别发到公开地方。

☁️ GitHub 备份

每天自动把数据推到你的一个私有 GitHub 仓库（单个文件 hubmate-backup.json，Git 历史就是备份历史），服务器挂了也能从 GitHub 恢复。推之前去掉所有用户的登录密码、Telegram Token、API 令牌、二次验证密钥和自动签到的请求头；数据没变就不推。Token 需要 repo 权限（classic Token 勾 repo，或 fine-grained Token 给仓库的 Contents 写权限）。备份里含所有用户的数据（v67 多用户），只有管理员能配、能下载、能恢复。

♻️ 重复清理

同名或同域名算一组

扫出名字相同、或网址域名相同的服务，留一个删一个。编辑复用原来的编辑框，删完列表会自动刷新。

🔐 密码复用

同一个密码用在多个账号上，一个站泄露了，其他站也跟着危险。下面按密码分组列出，点眼睛看密码原文，建议给这些账号换成不同的密码。只统计已录进来的账号，没录的不算。

🔐 共享账号库

一个账号只存一份，多服务共用：比如同一个邮箱账号在 3 个站都用，存进库里一次，3 个服务都链它；以后改一次密码，3 处跟着变。删库里的账号时，链它的服务自动变回本地副本（账号密码还留在服务里）。库里的密码只在登录后可见，公开页和备份里都不露密码原文之外的东西——备份里有完整数据，妥善保管。

🏷️ 分类管理

新分类会出现在筛选、添加下拉和首页收藏分组里

系统分类（收藏、每日签到、中转站、VPS、游戏、域名、已闲置）不能删除，可以改名换图标。自定义分类只有里面没有服务时才能删；有服务时请先去把服务编辑到其他分类，再回来删。

📝 记事本

只在登录后可见，公开页面和公开接口里都没有。重要的东西写下来，忘了回来搜。内容支持 Markdown：# 标题、**粗体**、*斜体*、`代码`、- 列表、> 引用、[链接](网址)，展开后按文章排版显示；编辑器里有工具栏，点 👁 预览能看到文章效果。
